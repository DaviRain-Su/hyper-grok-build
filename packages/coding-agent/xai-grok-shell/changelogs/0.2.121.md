# 0.2.121 — 2026-08-06

## Features

- **Background spawn** can keep unfinished parent work going instead of only polling the child.
- **Disk-full** is surfaced during live sessions instead of failing opaquely.
- **Queue reorder** lets any queued item move up or down; send-now never drops earlier queued text.
- **Disabled MCP stubs** appear only when they can be re-enabled.

## Bug Fixes

- **`/resume` search** finds sessions that load via `--resume`.
- **Restored child sessions** are registered so `--resume` does not 404.
- **API errors** show clean TUI banners; Cloudflare 52x and other 5xx sampling errors retry.
- **First-party API key** is probed before login is skipped.
