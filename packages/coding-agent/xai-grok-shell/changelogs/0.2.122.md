# 0.2.122 — 2026-08-07

## Features

- **`grok du`** shows what `~/.grok` uses on disk.
- **Session search** no longer locks the shared index when launching many shells.
- **Confirm before `/rewind`** on conversation-only rewinds.
- **Subagent bounds** measure and limit how many subagents a session runs at once.
- **Auto decision telemetry** is exposed for Auto mode.
- **Voice / Finance** tool-usage cards are typed with client render support.

## Bug Fixes

- **Leader version mismatch** is shown in scrollback.
- **Empty TUI exit** is faster.
- **Esc and [stop]** suppress task wakes like Ctrl+C.
- **WebLogin** users are told to run `grok update` before re-authenticating.
- **Colliding skills** stay invocable beside builtins.
